Prova subito: Vota su una scheda e rinomina la prima opzione. Poi cambia maxVotes nel TypeScript: il padre decide quando accettare la richiesta del figlio.

Padre
Possiede la lista e i voti. Aggiorna soltanto l’oggetto identificato dall’evento.

Figlio
Riceve option e un motivo di blocco. Non modifica direttamente i dati ricevuti.

Evento
voteRequested emette l’ID; recordVote decide cosa fare.

Nel TypeScript trovi prima VoteCard, poi VotingDemo, esportato come componente di ingresso. Il template HTML e il CSS separati appartengono al padre; il figlio ha template e stili accanto alla propria classe. Sono due vere istanze Angular, non una simulazione.

Il runner usa @Input, @Output ed EventEmitter, supportati dalla compilazione JIT. Le API input() e output() richiedono trasformazioni del compilatore Angular che questo runner non applica ancora. Separare i componenti in file importabili richiederà il runtime per progetti completi.
