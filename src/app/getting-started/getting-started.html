Prova subito: cambia message nel TypeScript, aggiungi una frase nell’HTML o scegli un nuovo colore nel CSS. La preview segue il tuo codice.

TypeScript Dati e comportamento: message e count.

HTML La vista: le doppie graffe mostrano i dati, (click) ascolta un’azione.

CSS L’aspetto: colori, spazi e la variante card--highlighted.

Una classe, un template, uno stile

@Component collega i tre file. selector dà al componente il nome da usare in una vista padre: <app-welcome-card />.

Ogni istanza ha i propri dati. Quando premi il pulsante, cambia count e Angular aggiorna il testo. Non serve riscrivere l’HTML a mano.

Qui modifichi un componente standalone con Angular core, common, forms e i pulsanti Angular Material. Puoi anche definire altri componenti nello stesso file TypeScript e collegarli nella vista. I progetti completi su più file arriveranno con un playground dedicato. Gli errori mostrati riguardano sintassi ed esecuzione; non c’è ancora il controllo completo dei tipi TypeScript.
